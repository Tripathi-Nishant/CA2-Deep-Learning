# DefectVision baseline report

## Problem framing

The training split contains only normal examples (`label == 0`), so a supervised
defect classifier cannot learn a positive class from this data. The baseline uses
one-class anomaly detection: normal image patches form a category-specific memory
bank, and a test image is defective when its most unusual patches are far from that
bank.

## Data analysis

The supplied data has 742 training images and 503 test images. The category counts
are train: bottle 135, cable 145, screw 208, hazelnut 254; test: bottle 83, cable
150, screw 160, hazelnut 110. All 1,245 referenced images exist and are RGB. The
source resolutions are 192, 224, 256, and 288 pixels. PNG is the dominant format
(620/742 train and 427/503 test). `outputs/eda_train.png` and
`outputs/synthetic_examples.png` are generated by the run.

## Method

The runnable local baseline resizes images to 192x192 and extracts six-by-six local
patch descriptors containing colour, intensity, contrast, and gradient statistics.
It augments the normal memory bank with right-angle rotations for rotation-sensitive
categories, while keeping cable unrotated. Scoring uses the mean distance of the
five most unusual patches to the nearest normal patch. Four-fold held-out normal
scoring and simple synthetic scratches, blobs, erasures, and spots provide a
validation signal without using test labels.

Thresholds are category-specific and use the 97th percentile of held-out normal
scores. This fixes an expected normal-image false-positive rate near 3% and avoids
pretending that synthetic defects are real labels. The generated submission uses
the required string labels `good` and `defective`, in the exact test CSV order.

## Limitations and next experiments

This is a CPU-safe fallback, not the final high-compute PatchCore ensemble. The
next upgrade should add cached pretrained WideResNet layer2/layer3 patch features,
FAISS or batched nearest-neighbour search, and a second feature family such as
DINOv2. Thresholds should then be selected from cross-fold synthetic results and
reviewed against unlabeled test-score histograms. Synthetic defects are only a
proxy, so improvements should be stable across defect types and folds rather than
chosen from a single score.

If the leaderboard differs strongly from local validation, first inspect category
defective rates and score histograms, then compare the percentile threshold with a
transductive two-cluster threshold. Do not use hidden labels or tune repeatedly to
small public-leaderboard changes.
